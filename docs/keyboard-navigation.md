# Keyboard screen navigation

Screen changes previously scrolled the viewport but left keyboard focus on removed controls or the document body. The main landmark now accepts programmatic focus, including the existing header link. New scenario, reveal, checkpoint and final views move focus to main without adding it to the ordinary Tab sequence. Practice closing returns focus to the session view. Editing allocation amounts does not move focus away from their controls.

When playback reaches an intermediate pause, focus moves to its heading so the next Tab reaches the continuation controls. Finishing the five-year reveal restores focus to the main view. Existing visible-focus styling applies; this change does not alter investment choices, persistence, returns or replay timing.

Browser regression checks cover keyboard activation, unchanged focus while editing, new-screen focus, intermediate replay pauses and returning from practice. Existing desktop/mobile and built-production journeys provide integration coverage. This is not a claim of a full screen-reader or accessibility certification.

Chart legends now use the normal dark label color, with colored line swatches. The prior gray and bronze series colors produced text contrast of about 3.82:1 and 3.84:1 on white; the normal legend text is about 5.39:1. The plotted lines keep their colors, and negative return numbers keep the approved red treatment. Focused browser assertions cover the two previously light labels.
