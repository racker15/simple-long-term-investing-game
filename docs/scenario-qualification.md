## Shared coverage, accounting and provenance limits

The committed broad numerical file contains 612 monthly observations per asset, January 1975–December 2025, for cash, bonds, US equity and international ex-US equity. All six displayed trailing twelve-month and subsequent sixty-month windows lie within that range. This coverage is an inspected numerical fact; final alignment, finiteness, freshness and scenario checks remain in the acceptance ledger.

Cash is the French one-month Treasury proxy; US equity is `Mkt-RF + RF`; international equity is a dividend-inclusive developed ex-US/EAFE-plus-Canada proxy rather than all global ex-US stocks. Bonds are a constructed rolling five-year Treasury exposure, using monthly-average yields, monthly coupons and a flat curve rather than an investable aggregate-bond fund. [Historical data methodology](historical-data.md) records transformations and source manifests.

The five new stock datasets use current daily USD Yahoo adjusted closes; the pilot uses a 2016 revision-pinned legacy snapshot. Prices are normalized to the final actual trading observation of each calendar month. Ratios represent a **dividend-adjusted return proxy**, not exact broker DRIP execution. Yahoo's dividend factors use the previous close; tax, fees, fractional shares and investor-specific reinvestment timing are absent. Cash distributions and splits must never be credited again. Later uniform scale factors cancel in ratios; that mathematical observation does not independently certify each vendor corporate-action factor.

The fifteen new stocks have tiny differences between independently requested starting and outcome Yahoo snapshots for the same historical dates. Rebasing to a common endpoint gives a maximum relative overlap-price error of `1.3353e-6` (about 1.34 ppm), with maximum absolute trailing-return difference `2.2464e-6` for GE. Final integration checks all thirteen overlapping endpoints against a five-ppm relative bound for these new stocks only; original September 1999 and broad checks retain `1e-12`. Larger inconsistencies must fail. The mechanism behind the vendor variation is unestablished. Locked starting bytes are preserved without an integrity repair, reselection or silent recomputation; audit records retain the discrepancies.

The current chart endpoint is unversioned. A raw SHA pins retrieved bytes and cannot guarantee that a future request returns the same bytes. Normalized endpoints permit deterministic offline rebuilding; the ignored raw cache permits deeper source checks when retained. Every required gap, invalid endpoint or unexplained security mapping must fail qualification rather than be filled or replaced with a convenient survivor.

Publication, observation, archive migration/digitization and retrieval dates are distinct. Starting news/macro sources need an established pre-cutoff publication or an explicitly modeled availability approximation. `asof-*` market records model then-observable underlying inputs; they are not claims that today's archive existed then. Unknown original publication dates on current issuer/action tables remain unknown in the separate action audit and may be nullable in outcome-only provenance; they cannot justify starting information. Post-cutoff recession determinations and revised macro readings belong only in outcomes or corroboration.
