# Engagement UI plan — October 6, 2026

The owner approved ideas 1–58 from the UI long-list. Ideas 59 (discussion mode) and 60 (sharing/reflection cards) are excluded. This plan preserves one winner prediction, one locked five-year allocation, static historical data, hidden future outcomes, first-choice history, and uncertainty rather than lucky-return scoring.

9. Stable scroll on details and review.
10. Locked-choice summary during reveal.
11. Warm paper, dark ink, restrained accents.
12. Stronger type hierarchy.

15. Portfolio is the strongest line.
16. Gains/losses are information, not reward signals.

18. Starting-date-safe era illustration.
19. Company names before tickers.
20. Consistent component spacing and styling.

## Verification and completion

For every batch: unit/render and aggregate checks plus focused desktop/mobile production browser checks. Test keyboard, repeat/back/refresh, state restoration, quota failure, no future/cohort leakage and no duplicate results. No new account, live-data, tracking, social reward or trading features. Deployed smoke uses isolated browser storage and preserves the owner's origin and saved progress. Full-list approval is not a claim that all items are already implemented.
